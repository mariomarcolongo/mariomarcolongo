## How I work

**Separate observation from interpretation.**
Document what was directly observed before making broader claims.

**Make assumptions visible.**
State the definitions, exclusions and judgments that affect the result.

**Preserve provenance.**
Keep outputs connected to inspectable sources, records, revisions and dates.

**Test behavior, not only structure.**
Verify edge cases, failure paths, releases and operational outcomes.

**Plan for maintenance.**
Treat updates, corrections, deployment recovery and documentation as part of the work.
